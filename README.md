# Product Explorer

React Native (Expo) app that browses products from the free DummyJSON REST API.

## Features
- Product list with thumbnails and prices
- Infinite scroll pagination (limit/skip)
- Debounced search
- Pull to refresh
- Product detail screen
- Loading, error and retry states

## Tech
React Native, Expo, React Navigation, fetch API

## Run locally
npm install
npx expo start
Scan the QR code with Expo Go.
